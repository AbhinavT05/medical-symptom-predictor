# MediPredict — Medical Symptom Disease Predictor

A full-stack machine learning web application that predicts diseases based on selected symptoms. Built with FastAPI, React, and Scikit-learn.

> ⚠️ **Disclaimer:** This project is for educational purposes only. It is not a substitute for professional medical advice, diagnosis, or treatment.

---

## Project Overview

MediPredict trains three classification models (Decision Tree, KNN, Random Forest) on a medical symptom dataset, automatically selects the best-performing one, and exposes it through a REST API. A clean React frontend lets users select symptoms and receive an instant prediction with confidence score, disease description, and recommended precautions.

---

## Features

- Select from 132 symptoms via a searchable interface
- Predicts across 41 disease categories
- Confidence score for each prediction
- Disease description and precautions from a local JSON file
- Model comparison page showing accuracy of all three algorithms
- No external AI APIs — fully self-contained ML pipeline

## Installation

### Prerequisites

- Python 3.10 or higher
- Node.js 18 or higher
- pip

---

### Step 1 — Clone and set up

```bash
git clone https://github.com/YOUR_USERNAME/medical-symptom-predictor.git
cd medical-symptom-predictor
```

### Step 2 — Get the dataset

1. Go to https://www.kaggle.com/datasets/kaushil268/disease-prediction-using-machine-learning
2. Download the dataset
3. Place both files in the `dataset/` folder:

```
dataset/
├── Training.csv
└── Testing.csv
```

### Step 3 — Install Python dependencies

```bash
pip install -r requirements.txt
```

### Step 4 — Train the model

```bash
python ml/train.py
```

Expected output:
```
decision_tree        accuracy = 1.0000
knn                  accuracy = 1.0000
random_forest        accuracy = 1.0000

Best model: random_forest (1.0000)

Saved:
  models/best_model.joblib
  models/symptom_cols.json
  models/metadata.json
```

### Step 5 — Start the backend

```bash
uvicorn backend.main:app --reload --port 8000
```

API docs available at: http://localhost:8000/docs

### Step 6 — Start the frontend

```bash
cd frontend
npm install
npm run dev
```

Open: http://localhost:5173

## API Endpoints

### `GET /api/symptoms`

Returns the full list of 132 symptom names used during training.

**Response:**
```json
{
  "symptoms": ["itching", "skin_rash", "nodal_skin_eruptions", "..."],
  "count": 132
}
```

---

### `POST /api/predict`

Predicts disease from a list of selected symptoms.

**Request:**
```json
{
  "symptoms": ["itching", "skin_rash", "nodal_skin_eruptions"]
}
```

**Response:**
```json
{
  "disease": "Fungal infection",
  "confidence": 97.0,
  "description": "A fungal infection occurs when a fungus invades body tissue...",
  "precautions": [
    "Keep skin clean and dry",
    "Avoid sharing personal items",
    "Use antifungal creams",
    "Wear breathable clothing"
  ],
  "symptoms_used": ["itching", "skin_rash", "nodal_skin_eruptions"]
}
```

---

### `GET /api/model-info`

Returns model metadata, accuracy comparison, and explanation.

**Response:**
```json
{
  "best_model": "random_forest",
  "accuracies": {
    "decision_tree": 1.0,
    "knn": 1.0,
    "random_forest": 1.0
  },
  "num_symptoms": 132,
  "num_diseases": 41,
  "dataset": "Disease Symptom Prediction — Kaggle",
  "algorithms": ["Decision Tree", "KNN (k=5)", "Random Forest (100 estimators)"],
  "why_best": "Random Forest was selected..."
}
```

## ML Pipeline

```
dataset/Training.csv + Testing.csv
        ↓
preprocess.py  →  drop unnamed cols, split X / y
        ↓
train.py  →  fit Decision Tree, KNN, Random Forest
        ↓
compare test accuracy
        ↓
save best model → models/best_model.joblib
                → models/symptom_cols.json
                → models/metadata.json
        ↓
FastAPI loads model once on startup
        ↓
POST /api/predict  →  binary feature vector  →  predict()  →  response
```

## Interview Talking Points

**Why does the model show 100% accuracy?**
The Kaggle dataset is synthetically generated and perfectly balanced — each disease maps to an exact set of symptoms with no noise. In a real clinical setting, accuracy would be lower due to overlapping symptoms and patient variability.

**Why Random Forest over Decision Tree?**
Both achieve the same accuracy on this dataset, but Random Forest is selected because it is an ensemble method that reduces variance and overfitting on unseen data. It also produces better-calibrated probability estimates via `predict_proba`, which powers the confidence score.

**How does prediction work?**
The selected symptoms are mapped to a 132-dimensional binary vector (1 = symptom present, 0 = absent). This vector is passed to `model.predict()` for the disease label and `model.predict_proba()` for the confidence score.

**Why no authentication or database?**
This is an ML portfolio project. Adding auth and a database would shift focus away from the ML pipeline, which is the core learning objective.
